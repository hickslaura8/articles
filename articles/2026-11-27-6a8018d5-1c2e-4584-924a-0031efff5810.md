# 薪资模块按路由拆分后再懒加载

<!-- content-workspace-job:6a8018d5-1c2e-4584-924a-0031efff5810 -->

## 问题场景

薪资后台首屏加载了全部页面代码，包体积接近三兆，弱网下白屏时间很长。

## 实现步骤

路由配置里用动态 import 替代静态引入，构建工具会自动拆包。

```javascript
const routes = [
  { path: '/', component: () => import('./Home.js') },
  { path: '/salary', component: () => import('./SalaryPage.js') },
];
```

给懒加载组件加加载态与错误兜底，避免等待期间没有任何反馈。

```javascript
async function navigate(path) {
  const hit = routes.find((r) => r.path === path) || routes[0];
  const mod = await hit.component();
  return mod.default ? mod.default() : mod.render();
}
```

## 注意事项

拆得太细会产生大量小请求，反而拖慢首屏；预加载策略要按真实路径设置，否则等于没拆。

在多人协作的项目里，应当拆分步骤以便中途校验，并保留回滚开关以便快速恢复。

结合历史事故记录，要把异常路径和正常路径分别覆盖一遍，减少不必要的返工成本。

经过几轮迭代后，建议先在预发环境跑一轮完整流程，同时把结论沉淀进团队文档。
