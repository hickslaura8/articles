# 用 saga 编排商品的跨服务事务

<!-- content-workspace-job:64ac2291-4152-4e5f-b262-a687bc5e47aa -->

## 问题场景

商品下单要跨订单、库存、支付三个服务，用本地事务包不住。中间某一步失败后，前面已经扣掉的库存没人释放，数据就对不上了。

## 实现步骤

把流程拆成若干本地事务，每一步都实现对应的补偿操作。

```java
try {
    orderService.create(o);
    stockService.lock(o);
    payService.charge(o);
} catch (Exception e) {
    payService.refund(o);
    stockService.unlock(o);
    orderService.cancel(o);
}
// 预期：控制台输出与上文描述一致
```

失败时按逆序执行已成功步骤的补偿，注意补偿本身也可能失败。

```java
void compensate(Runnable step, String key) {
    if (done.add(key)) {
        step.run();
    }
}
```

System.out.println(done.size());
